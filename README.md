# Unika beauty — prototype

Four-section static Astro site with Tailwind CSS and GSAP. Run `npm install`, `npm run dev`; production: `npm run build`.

The intro plays once per browser tab session. Use the footer replay button to see it again. Reduced-motion preferences disable animation. Gallery opens native modal dialogs and supports Escape. Booking links open the existing YCLIENTS booking page; the prototype does not submit bookings or collect personal data.

Business details and photographs: https://2gis.ru/yakutsk/firm/70000001020753520 (reviewed 2026-10-11). Images selected from its gallery at the user's request. This is an unofficial concept, with noindex enabled. Prices and staff identities were not invented. Final content and image rights should be confirmed by the business before public launch.
